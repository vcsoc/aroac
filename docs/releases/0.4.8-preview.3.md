# AROAC 0.4.8-preview.3 — macOS ARM64 prerelease

This preview adds a full-page Radio channels workspace with local, profile-private saved channel drafts, inline editing, CSV import/export, and the ability to capture inspected memory entries as **unverified** drafts. It also contains a guarded Linux-only UV-5R USB programming preview; **USB reading/writing is not implemented or validated on macOS**. See [hardware safety requirements and limitations](../radio-programming.md) before using any radio-programming feature on a supported Linux machine. This release contains **no Linux binary**, and the Linux hardware workflow has not been tested as part of this macOS release. Do not transmit based on imported or unverified settings. The core desktop remains all-in-one and local-first, with its own SQLite database and application logic; no separate server installation or account service is required. Online maps and data providers may still receive requests. Optional encrypted relay remains an unaudited preview.

## Download and verify

From [GitHub Releases · v0.4.8-preview.3](https://github.com/vcsoc/aroac/releases/tag/v0.4.8-preview.3), download either `AROAC-0.4.8-preview.3-arm64.dmg` or `AROAC-0.4.8-preview.3-arm64-mac.zip` and `AROAC-0.4.8-preview.3-macOS-arm64-SHA256SUMS.txt`. Verify the downloaded package with `shasum -a 256` against its manifest entry. To run `shasum -a 256 -c AROAC-0.4.8-preview.3-macOS-arm64-SHA256SUMS.txt` in full, also download the other package and both `.blockmap` files. `latest-mac.yml` is updater metadata; a live update was not exercised. The binaries exceed GitHub's Git-file limit and are release assets, not Git blobs; the checksum manifest is committed under `releases/`. Checksums establish download integrity, not independent publisher identity.

## Tested platforms and limits

Built with Electron/Node on macOS ARM64. Of 90 Node tests, 86 passed and 4 Linux-only installer tests were skipped. The packaged application passed standalone offline desktop, guidance/tutorial, account/profile/device, and radio-channel draft/list smoke tests. ZIP and DMG integrity plus SHA-256 checks passed. No physical radio was connected on macOS. The existing release-ten smoke test is known to fail on the macOS `/private/var` versus `/var` temporary-path comparison and was not part of this preview's smoke run. The installer UI, updater, Windows, Linux packages and mobile apps were not tested for this prerelease. The macOS application is **not Developer ID signed or notarized**; Gatekeeper may block opening it. iOS still needs a local SQLite adapter and Xcode for compilation/signing. Android remains blocked pending a genuinely JDK-free application port and physical-device validation (minimum product target Android 16/API 36); the old Capacitor scaffold is not a release. No Java, JDK or .NET tooling was used.
